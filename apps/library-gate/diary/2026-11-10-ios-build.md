# Library gate: iOS build

## Rough

The manifest declared iOS, but the app had no Apple host crate. The native build could not resolve its target.

## Lean in

Use the shared Apple host with the app’s existing data source and Contract UI.

## Needed

An Apple adapter and an explicit iOS store level of `0`; this fixture has no update stream.

## Checkpoints

Built on clean Ubuntu 24.04. The unchanged bundle passed Apple's strict signature verification, launched on iOS 27.1, and completed the library tree checks with a screenshot.
